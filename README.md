# Mathematical Optimization Algorithms

Labs from the "Mathematical Optimization Algorithms" course at Warsaw University of Technology. Covers optimization, statistical analysis, Monte Carlo methods, and supply chain modeling in Python.

## Labs

### 1. Linear Programming - Tea Distribution

Profit maximization for a tea company distributing across 6 European markets. Formulated as an LP problem with production capacity, raw material, and market share constraints using PuLP.

### 2. Statistical Analysis - World Happiness

Exploratory analysis of the World Happiness dataset: correlation matrices, hypothesis testing (t-tests), linear and multiple regression (scikit-learn), probability estimation with normal distributions.

### 3. Monte Carlo & Time Series - Stock Prices

Monte Carlo simulation of FB and GOOG stock prices, ARIMA forecasting, power analysis, and time series decomposition using real historical price data.

### 4. Supply Chain Optimization

Multi-stage supply chain cost minimization (manufacturing -> distribution -> warehouse -> market) using linear programming. Includes geographic visualization with Folium, sensitivity analysis, and carbon footprint estimation.

## Tech

Python, pandas, NumPy, PuLP, scikit-learn, SciPy, statsmodels, Matplotlib, Folium
